# Theory: scripts, functions and local functions in MATLAB

## Script or function?
A **script** is a list of commands in a `.m` file. It runs in the *base workspace*: its variables stay visible afterwards, and it can see (and overwrite) whatever was there. Handy for quick work, risky for bigger programs. A **function** has inputs, outputs and its **own workspace**: its variables vanish when it returns, and only the outputs leave. That isolation is why programs are built from functions.

Several outputs go in brackets, `function [a, b] = name(x, y)`: assign each (`a = ...;`) before `end`, and call with `[p, q] = name(1, 2);`. End lines with `;` or MATLAB prints the result.

## Function files and local functions
A **function file** starts with `function` (comments before it are fine). Its first function must have the **same name as the file**; that is the one you call from outside. Functions after it are **local functions**: only code in that file can call them. Put a function in its own file `name.m` when other files need it. MATLAB (since R2016b) also allows local functions at the *end of a script*, but GNU Octave, which checks your code, does not, so here a file with several functions is a function file.

## Worked example (different physics, same steps)
The cyclotron frequency is $\omega_c = |q| B / m$, and the frequency in hertz is $f = \omega_c / 2\pi$. In a file `demo.m`:

```matlab
function demo()
  w = omega_c(1.602e-19, 1.673e-27, 2.0);   % proton in a 2 T field
  fprintf('f = %.3e Hz\n', w / (2*pi));
end

function w = omega_c(q, m, B)
  w = abs(q) * B / m;
end
```

Typing `demo` prints `f = 3.048e+07 Hz`. Inside `demo`, the names `q`, `m` and `B` do not exist: they belong to `omega_c` and are gone once it returns. Only the *value* of `w` comes back. (Today's physics: $r_L = v_\perp/\omega_c$, and at equal temperature $v \propto 1/\sqrt{m}$, so $r_L \propto \sqrt{m}$.)

## Tips and pitfalls
- **Keep file name = first function name**, and run it from its own folder (or add it to the path).
- **Forgot to assign the output?** "Output argument not assigned" (MATLAB) or "value undefined" (Octave).
- **Don't name variables after built-ins** (`sum`, `max`, `i`): the variable hides the function.
